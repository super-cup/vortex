# 打印与玩法指南 · 旋涡 / VORTEX

## 1. 文件

| 文件 | 数量 | 说明 |
|---|---|---|
| `stl/vortex_funnel.stl` | ×1 | 漏斗 + 双螺旋护栏（Ø100 × 70） |
| `stl/vortex_bead.stl` | ×3 | 珠子 Ø10（或用 10 mm 钢珠） |
| `stl/vortex_plate.stl` | ×1 | 托盘 Ø130 × 8 |
| `stl/vortex_funnel_section.stl` | 不要打 | 1/4 剖切版，仅供预览内部 |

---

## 2. 切片

| 项 | 值 |
|---|---|
| 材料 | PLA（哑光）或 PETG |
| 喷嘴 / 层高 | 0.4 mm / 0.20 mm |
| 壁 / 填充 | 3 墙 / 15% gyroid |
| 支撑 | **关闭** |
| 底座 | 建议 3 mm brim（漏斗底环只有一圈接触面） |
| 速度 | 外壁 40 mm/s；护栏附近 30 mm/s |

---

## 3. 摆放

- **漏斗**：大口朝下（底环 Ø100 贴床），顶部 Ø40 朝上。
- **珠子**：正常摆放。
- **托盘**：平放。

---

## 4. 装配

1. 托盘放桌上；
2. 漏斗放在托盘中央；
3. 珠子从顶部孔投入。

不需要工具、不需要胶水。

---

## 5. 调校

| 症状 | 原因 | 处理 |
|---|---|---|
| 珠子在顶部卡住 | 投珠孔边缘有毛刺 | 用刀片沿孔口 45° 倒角轻刮 |
| 珠子滑一两圈就停 | 护栏内壁层纹太糙 | 800 目砂纸沿两条护栏的内侧面轻磨 |
| 珠子直接冲到底 | 锥面太陡 / 珠子太重 | 减小 `R_BOT`（锥面更缓），或换轻珠 |
| 珠子在中途翻出 | 速度太快 / 护栏太矮 | 把 `RAIL_H` 从 3.5 加到 4.0（需重打） |
| 漏斗与托盘不配 | 打印公差 | 托盘凹槽 Ø116，漏斗底 Ø100，有 16 mm 余量 |

---

## 6. 材料建议

| 材料 | 效果 |
|---|---|
| PLA 哑光 | 摩擦适中，珠子速度可控，声音偏闷 |
| PETG | 更滑，珠子更快，更容易"飞出去" |
| 钢珠 Ø10 | 惯性大、声音脆，但会更快到底 |

**不推荐** TPU（护栏会变形，珠子会卡）。
