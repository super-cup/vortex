# 设计说明 · 旋涡 / VORTEX

## 1. 概念

商场里的"硬币收集器"：一枚硬币投进漏斗，沿内壁螺旋下降，转很多圈才掉进洞里。

这个玩具是它的 3D 打印版，但把"硬币"换成了"珠子"，把"光面内壁"换成了**双螺旋护栏**。

核心体验：**投一颗珠子，看它自己转 11 圈。**

---

## 2. 几何

### 2.1 漏斗

截头圆锥，内表面：

```
r(v) = R_TOP + (R_BOT - R_TOP)·v      v ∈ [0,1]（0=顶，1=底）
z(v) = H·(1 - v)
```

默认 R_TOP=20、R_BOT=50、H=70 → 锥面倾角 `atan(30/70) = 23.2°`。

这个角度很关键：

- **太小**（<15°）：珠子会被摩擦"停住"，不滑；
- **太大**（>35°）：珠子直接冲到底，圈数还没走完就飞出去了；
- **23°**：珠子有稳定的加速度，但不会失控。

### 2.2 双螺旋护栏

两条矩形截面的墙，沿螺旋路径扫掠：

```
θ(v) = 2π·TURNS·v
路径半径 = r(v) - RAIL_GAP/2 ± RAIL_GAP/2
截面 = 1.5 mm（厚）× 3.5 mm（高），底部嵌入锥面 0.6 mm
```

- 两条护栏的中心距 `RAIL_GAP=10`，内净宽 8；
- 珠子 Ø10 → 珠子卡在两条护栏之间，坐在锥面上，珠心离锥面 3 mm；
- 护栏高 3.5 > 3 → 珠子的"赤道"低于护栏顶，翻不出去。

### 2.3 为什么珠子会螺旋

光面上的珠子不会螺旋——它只会沿最陡方向（径向）直线下滑。

两条护栏把"螺旋"变成**几何约束**：珠子夹在中间，只能沿护栏走。护栏同时提供向心约束，挡住离心力。

**这不是靠摩擦力，是靠几何。**

---

## 3. 为什么是护栏，不是刻槽

初版在锥面上刻 V 槽（更接近真正的"硬币收集器"纹路），遇到两个问题：

### 3.1 网格走样

锥面上的螺旋槽，在 `(θ, v)` 参数网格上是一条斜线。槽宽 6 mm 对应的 `Δv ≈ 0.002`，要把槽画圆滑需要 `nv ≈ 2750`——顶点数爆炸（>400 万）。

### 3.2 布尔太慢

用 CAD 扫掠 + 差集可以做精确槽，但 11 圈 × 720 段的扫掠在 cadquery 里要跑很久，且生成的网格仍然很大。

### 3.3 护栏的解法

护栏是"凸"的，不是"凹"的：

- 矩形截面沿螺旋扫掠，5760 面，秒级；
- 护栏是竖直薄墙，**免支撑**；
- 护栏高度（3.5）独立于壁厚（2.5）——这比"槽深必须小于壁厚"自由得多。

**同一个功能，换一种拓扑：从"刻掉材料"变成"加上材料"，从"难打印"变成"免支撑"。**

## 5. 运动

### 5.1 加速度

珠子沿锥面下滑的重力分量：

```
a = g·sin(23.2°) ≈ 0.39g ≈ 3.9 m/s²
```

但护栏把运动约束成螺旋，实际沿轨道的加速度约为 `a·cos(螺旋角) ≈ 3.9 m/s²`（螺旋角只有 1.5°，可忽略）。

### 5.2 速度

理想情况下（无摩擦），从顶部到 11 圈底部下降 70 mm：

```
v = √(2·g·h) = √(2×9.81×0.07) ≈ 1.17 m/s
```

实际因为有护栏碰撞、层纹摩擦，速度会低很多（估计 0.3–0.6 m/s）。这就是为什么它能"转很多圈"而不是"直接掉下去"。

### 5.3 什么时候会飞出去

离心力超过护栏能提供的约束时：

```
v > √(g·r) = √(9.81×0.035) ≈ 0.59 m/s
```

**所以"飞出去"是设计的一部分**：投得越猛、珠子越滑，越可能在最后几圈翻出护栏，掉进托盘。这不是 bug。

## 6. 打印性

| 项 | 结果 |

| 网格 | 244,530 面，水密，单壳（漏斗 + 双护栏 union） |
| 体积 | 59.6 cm³（实心等价），约 25 g @15% 填充 |
| 悬垂 | 锥面 23.2°、护栏侧面竖直、护栏顶面水平——全部 ≤45°，**免支撑** |
| 桥接 | 顶部投珠孔 Ø14，桥接 14 mm，可接受 |
| 打印时间 | 约 5 h |

**注意**：漏斗壁厚 2.5，护栏嵌入 0.6，槽深（护栏高）3.5——三者关系是 `WALL > 嵌入深度`，改参数时不要破坏这个约束。

## 7. 玩法

1. **投珠**：从顶部孔丢入，看它转 11 圈。
2. **比赛**：3 颗珠子同时投，看谁先到底（摩擦差异会让结果不同）。
3. **能转到底吗**：刻意"斜投"让珠子获得切向初速度，看它会不会在最后几圈飞出。
4. **听**：珠子越转越快，"嗒嗒"声越来越密，最后"啪"地落盘。

## 8. 已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 珠子在顶部卡住 | 投不进去 | 顶部孔 Ø14 > 珠径 10；孔的边缘做 45° 倒角 |
| 珠子中途停住 | 摩擦太大 | 打印后沿护栏内壁轻磨；或用钢珠 |
| 珠子太快飞出 | 掉进托盘（设计内） | 想避免就降低投掷高度 |
| 5 小时打印时间 | 耐心 | 可把 `TURNS` 降到 8，体积减少 ~30% |
| 漏斗壁薄（2.5） | 易碎 | 用 PETG，或 `WALL` 改 3.0 |
